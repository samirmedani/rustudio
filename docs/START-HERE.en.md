# Rustudio on Windows

Rustudio is an [open-source](../LICENSE) app for detecting and configuring desk hardware on Windows 10 and 11. Each device family has its own module. Supported devices appear automatically under **Mes appareils** (My devices) when connected.

[Download Rustudio-Setup.exe](https://github.com/samirmedani/rustudio/releases/latest/download/Rustudio-Setup.exe), run the installer, and open **Mes appareils**. The app interface is in French. No account or telemetry.

The current release supports the [Attack Shark R5 Ultra](R5-ULTRA.md) mouse, the [Cooler Master MK770](MK770.md) keyboard (USB) and the [TC-Helicon GoXLR Mini](GOXLR-MINI.md) audio interface. The GoXLR Mini module uses the official TC-Helicon driver. See the module pages for hardware and testing limits.

Want to add another device? [Request a module](https://github.com/samirmedani/rustudio/issues/new?template=appareil.yml) and tell us its model, connection type and the setting you need most. You can also help test a module, contribute code, or improve the docs. Community modules keep their creator's credit and ship in Rustudio after review.

See the [contribution guide](../CONTRIBUTING.md) and [device module guide](MODULES.md) to get started. English bug reports and device requests are welcome.
